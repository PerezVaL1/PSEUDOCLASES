:valid:invalid:user-valid:user-invalid

Escribe un correo. Las versiones user- esperan a que interactúes y salgas del campo.

CSS
.fv:valid{border-color:var(--verde);background:#EEF8E6}
.fv:invalid{border-color:var(--rojo);background:#FDEEEA}
.fu:user-invalid{border-color:var(--rojo);background:#FDEEEA}
.fu:user-valid{border-color:var(--verde);background:#EEF8E6}
HTML
<input class="fv" type="email" placeholder="correo@sena.edu.co" required><input class="fu" type="email" placeholder="Con :user-invalid" required>
