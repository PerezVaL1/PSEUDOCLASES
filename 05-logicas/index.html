:not()

  • A
  • B
  • C (.x)
CSS
.ln{list-style:none;padding:0;margin:0;width:100%}
.ln li{padding:.4rem .7rem;margin:2px 0;background:#EEF2EB}
.ln li:not(.x){background:var(--verde);color:#fff}

:is():where()

:is() toma la especificidad del más fuerte; :where() siempre vale 0, por eso pierde frente a .isw .pp.

Título h4

Título h5

Verde: gana .isw .pp

Rojo: :where(.isw) p

CSS
.isw :is(h4,h5){background:var(--tinta);color:#fff;padding:.3rem .6rem;margin:.2rem 0}
:where(.isw) p{color:var(--rojo)}
.isw .pp{color:var(--verde-osc)}
HTML
<div class="isw"><h4>Título h4</h4><h5>Título h5</h5><p class="pp">Verde: gana .isw .pp</p><p>Rojo: :where(.isw) p</p></div>
