:lang():dir()

Hola

Texto de izquierda a derecha

CSS
.lg{padding-left:.6rem;border-left:5px solid}
.lg:lang(es){border-color:var(--verde)}
.lg:lang(en){border-color:var(--amarillo)}
.lg:lang(fr){border-color:var(--rojo)}
.dr{padding:.4rem .6rem;width:100%}
.dr:dir(ltr){border-left:5px solid var(--tinta)}
.dr:dir(rtl){border-right:5px solid var(--rojo);text-align:right}
HTML
<p class="lg" lang="es">Hola</p><p class="dr" dir="ltr">Texto de izquierda a derecha</p>

CSS
.det{width:100%;border:2px solid var(--linea);padding:.5rem .8rem;border-radius:6px}

:modal:popover-open

Un dialog abierto con showModal() es :modal; con show() no lo es.

Soy un popover
CSS
.dg{border:3px dashed var(--linea);border-radius:8px;padding:1.2rem}

.pp2:popover-open{border:3px solid var(--amarillo);padding:1rem;border-radius:8px}
HTML
<dialog class="dg"><p>Soy un diálogo.</p><form method="dialog"><button>Cerrar</button></form></dialog><div popover class="pp2">Soy un popover</div><button popovertarget="pp2x">Abrir popover</button>
