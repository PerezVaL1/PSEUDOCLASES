:host:host():host-context():has-slotted

:host-context() solo existe en Chrome y Safari; :has-slotted es muy reciente.

TítuloContenido de la tarjeta.
CSS
/* dentro del Shadow DOM (script.js) */
:host{display:block;padding:.8rem;border:2px solid #CBD6C6;border-radius:8px;background:#fff}
:host(.activa){border-color:#39A900;box-shadow:0 4px 0 #39A900}
:host-context(.oscuro){background:#00304D;color:#fff}
::slotted([slot=titulo]){margin:0 0 .3rem;font-weight:700}
slot[name=extra]:has-slotted{display:block;border-top:1px dashed currentColor;margin-top:.5rem}
HTML
<tarjeta-x><span slot="titulo">Título</span>Contenido de la tarjeta.</tarjeta-x>

:state()

Estados personalizados definidos con ElementInternals.states.

Guardar
CSS
boton-x{display:inline-block;padding:.5rem 1rem;border:2px solid var(--tinta);border-radius:6px}
boton-x:state(cargando){background:var(--amarillo);border-style:dashed}
HTML
<boton-x>Guardar</boton-x>

:defined

El elemento no está “definido” hasta registrarlo con customElements.define().

Aún sin definir
CSS
lazy-x{display:block;padding:.6rem;border-radius:6px;width:100%}
lazy-x:not(:defined){background:#FDEEEA;color:var(--rojo)}
lazy-x:defined{background:#EEF8E6;color:var(--verde-osc)}
HTML
<lazy-x>Aún sin definir</lazy-x>
