:first-child:last-child:only-child

Quita elementos hasta que quede uno solo.

  • Uno
  • Dos
  • Tres
CSS
.li1 li:first-child{background:var(--verde);color:#fff}
.li1 li:last-child{background:var(--tinta);color:#fff}
.li1 li:only-child{background:var(--amarillo);font-weight:700}
HTML
<ul class="li1"><li>Uno</li><li>Dos</li><li>Tres</li></ul>

:first-of-type:last-of-type:nth-of-type():nth-last-of-type():only-of-type

CSS
.ty p:first-of-type{background:var(--verde);color:#fff}
.ty p:last-of-type{background:var(--tinta);color:#fff}
.ty p:nth-of-type(2){outline:2px solid var(--amarillo);outline-offset:-2px}
.ty p:nth-last-of-type(2){outline:2px dotted var(--rojo);outline-offset:-2px}
.ty span:only-of-type{background:var(--amarillo);font-weight:700}

<div class="ty"><p>P1</p><span>Span</span><p>P2</p><p>P3</p><p>P4</p></div>
