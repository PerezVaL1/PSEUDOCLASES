:link:visited:any-link

El primer enlace apunta a esta misma página, así que el navegador lo marca como visitado.

Esta página (visitada)Enlace nuevoSin href
CSS
.lk:link{color:var(--verde-osc);font-weight:600}
.lk:visited{color:#7B3FA0}
.lk:any-link{text-decoration-thickness:2px;text-underline-offset:4px}
.lk:not(:any-link){color:var(--gris)}
HTML
<a class="lk" href="">Esta página (visitada)</a><a class="lk" href="https://example.org/nunca-visitado-xyz">Enlace nuevo</a><a class="lk">Sin href</a>

:target

Haz clic en los enlaces: la caja cuyo id coincide con el # de la URL se resalta.

Caja 1Caja 2Quitar
Caja 1
Caja 2
CSS
.cj:target{background:var(--amarillo);font-weight:700;box-shadow:0 0 0 4px #FDC30066}
HTML
<a href="#caja1">Caja 1</a><a href="#caja2">Caja 2</a><a href="#quitar">Quitar</a><div class="cj" id="caja1">Caja 1</div><div class="cj" id="caja2">Caja 2</div>

:target-within

Experimental. Se muestra con :has(:target) como alternativa y con :target-within donde exista.

Activar

Contenido dentro del contenedor

CSS
.tw{padding:.7rem;border:2px solid var(--linea);border-radius:8px;width:100%}
.tw:has(:target){border-color:var(--verde);background:#EEF8E6}
@supports selector(:target-within){.tw:target-within{border-width:4px}}
HTML
<div class="tw"><a href="#tw-a">Activar</a><p id="tw-a">Contenido dentro del contenedor</p></div>
