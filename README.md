# Pseudoclases de CSS

Catálogo interactivo, una carpeta por categoría. Abre `index.html` (o la carpeta en VS Code con Live Server).

```
pseudoclases-css/
├── index.html
├── assets/            (base.css, app.js compartidos)
├── 01-accion-usuario/
├── 02-enlaces-ubicacion/
├── 03-formularios/
├── 04-estructurales/
├── 05-logicas/
├── 06-idioma-y-estado/
├── 07-multimedia/
├── 08-shadow-dom/
└── 09-compatibilidad/   (detector en vivo de todas las pseudoclases)
```
Cada carpeta tiene `index.html`, `styles.css` y `script.js`.

## Subir a GitHub
```bash
git init && git add . && git commit -m "Catálogo de pseudoclases CSS"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/pseudoclases-css.git
git push -u origin main
```
