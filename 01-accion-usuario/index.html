:hover:active

Pasa el mouse y mantén presionado el clic.

CSS
.b1{padding:.6rem 1.2rem;border:2px solid var(--tinta);background:#fff;border-radius:6px;transition:.15s}
.b1:hover{background:var(--verde);color:#fff;border-color:var(--verde)}
.b1:active{transform:scale(.92);background:var(--verde-osc)}
HTML
<button class="b1">Presióname</button>

:focus:focus-visible:focus-within

Usa Tab para recorrer. El contenedor reacciona cuando algo dentro tiene foco.

CSS
.fg{display:flex;gap:.5rem;flex-wrap:wrap;padding:.8rem;border:2px dashed var(--linea);border-radius:8px}
.fg:focus-within{border-color:var(--verde);background:#EEF8E6}
.fi:focus{outline:none;border-color:var(--amarillo);box-shadow:0 0 0 3px #FDC30066}
.fb:focus-visible{outline:3px solid var(--tinta);outline-offset:3px}
HTML
<div class="fg"><input class="fi" placeholder="Escribe aquí"><button class="fb">Botón</button><button class="fb">Otro botón</button></div>
